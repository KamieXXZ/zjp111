# 图片优化工具

这个工具使用 Imagemin 来批量压缩 assets 目录中的所有图片，并将其转换为适合网页使用的格式。

## 安装依赖

在运行此工具之前，请确保已安装所有必要的依赖：

```bash
npm install
```

## 使用方法

运行以下命令来优化所有图片：

```bash
npm run optimize
```

或者直接运行脚本：

```bash
node optimize-images.js
```

## 功能说明

- 该工具会递归扫描 `assets` 目录下的所有图片文件
- 对于 JPEG 图片，使用 MozJPEG 进行压缩，质量设置为 80%
- 对于 PNG 图片，使用 PngQuant 进行压缩，质量范围设置为 60-80%
- 对于 SVG 图片，使用 SVGO 进行优化
- 所有 JPEG 和 PNG 图片都会额外生成 WebP 格式版本
- 优化后的图片会保存在 `assets-optimized` 目录中，并保持原有的目录结构
- 控制台会显示每个文件的压缩情况，包括节省的字节数和百分比

## 注意事项

- 原始图片不会被修改，所有优化后的图片都会保存在新目录中
- 建议在运行前备份重要的图片资源
- 优化完成后，可以手动检查 `assets-optimized` 目录中的图片，确认效果满意后再替换原始图片
